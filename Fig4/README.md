# Fig 4 — Recurrent E–I spiking network with plasticity

Generates **manuscript Fig. 4**: a 300-E + 75-I spiking network that
self-organises through Hebbian and voltage-STDP plasticity into a
high-CV, high-ICE regime.  Reconstruction error decreases while
population CV and sparseness rise; ICE and mutual-information rate
both increase during training.  The network column of **manuscript
Fig. 5** (`figure5_network.fig`) — restricted to the spatiotemporal
operating points — is exported by these scripts and consumed in
`Fig5/`.

## Entry points

| Script                       | Produces                                                  |
| ---------------------------- | --------------------------------------------------------- |
| `figure4_main.m`             | **Main pipeline** — network simulation, training trajectory, all panels |
| `Learning_testentr.m`        | Entropy-rate evaluation along the learning trajectory     |
| `figure4_errbar.m`           | Bootstrap error-bar overlay                               |
| `runnet.m`                   | Stand-alone network forward-pass (called by main script)  |
| `redo_fig4_plots.m`          | Re-plot panels from saved checkpoint                      |
| `figure4_legacy.m`           | Earlier version, retained for reference                   |

Output panel `.fig` files:

| File              | Used in                                  |
| ----------------- | ---------------------------------------- |
| `figure4_t.fig`   | Fig. 4 — current/spike-time traces       |

Typical workflow:

```bash
matlab -batch "figure4_main"            # writes checkpoint.mat
matlab -batch "Learning_testentr"
matlab -batch "figure4_errbar"
```

## Model

* 300 excitatory + 75 inhibitory spiking neurons.
* Voltage-based STDP rule on recurrent weights Ω; Hebbian rule with
  decay on feedforward weights F (Methods §3.6).
* 3-dimensional input signal; frozen-stimulus paradigm (10 repeats
  per stimulus) for mutual-information evaluation.
* Full parameter list in Supp Table S9.

## Outputs

* `checkpoint.mat` — full simulation state (≈ 122 MB; **not** tracked
  by git, regenerated by re-running `figure4_main`).
* `figure4_state.mat`, `learned_o_2025_20.mat`, `Info_all_100.mat`,
  `500_rec.mat` — intermediate state snapshots.
* `.fig` panels for Fig. 4 and the network column of Fig. 5.
